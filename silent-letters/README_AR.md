# الحروف التي تُكتب ولا تُقرأ (بدون صور)

`Written-Not-Read.pptx`: 20 شريحة، الحرف الذي لا يُقرأ باللون الأحمر، وما نقرؤه بدلاً منه بالأخضر، والنطق بحروف لاتينية. **العناوين والتوضيحات وملاحظات المعلّم بالإنجليزية** (لغير العرب)، والأمثلة القرآنية بالعربية.

1. **كيف نعرفها:** الدائرة الصغيرة «۟» (لا تُقرأ أبداً)، والصفر المستطيل «۠» (تُقرأ عند الوقف فقط)، وبلا علامة (تسقط في الوصل).
2. **الدائرة الصغيرة:** قَالُوا۟، ءَامَنُوا۟، مِا۟ئَةَ، مِا۟ئَتَيۡنِ، أُو۟لَٰٓئِكَ، أُو۟لُوا۟ ٱلۡأَلۡبَٰبِ، لِشَا۟يۡءٍ، ثَمُودَا۟، بِأَيۡي۟دٍ.
3. **الصفر المستطيل (وصلاً / وقفاً):** أَنَا۠، لَّٰكِنَّا۠، ٱلظُّنُونَا۠، ٱلسَّبِيلَا۠.
4. **بلا علامة، تسقط في الوصل:** همزة الوصل (بِسۡمِ ٱللَّهِ)، اللام الشمسية (ٱلشَّمۡسُ)، حرف المد قبل ساكن (فِي ٱلۡأَرۡضِ، وَقَالُوا۟ ٱلۡحَمۡدُ)، وألف تنوين الفتح (عَلِيمًا: وصلاً عَلِيمَنۡ، وقفاً عَلِيمَا).
5. **يُكتب حرف ويُقرأ غيره:** ٱلصَّلَوٰةَ ← الصَّلَاةَ.
