# ألعاب الفتحة التفاعلية (Glassy، تعليمات بالإنجليزية)

16 ملفاً (نفس ترتيب الحروف)، **أزرار تعمل داخل العرض** (Slide Show): الطفل يضغط على الإجابة.

- **Game 1 · Find the fathah:** «Tap the letter with FATHAH» بين بَ / بِ / بُ.
- **Game 2 · Find the sound:** «Tap: "ba"» بين ثلاثة حروف بالفتحة (لا تُعرض الحروف المتشابهة صوتاً معاً: ح/ه، س/ص، د/ض، ت/ط…).
- **Game 3 · Build it:** «ba + ta = ?» بين الكلمة الصحيحة والمعكوسة وأخرى.
- **Game 4 · Read the word:** «Which word says "kataba"?» بكلمات حقيقية بالفتحة.

الإجابة الصحيحة ← شريحة **Great job!** بنجوم تظهر وحدها وصوت فرح، وزر **Next**. الإجابة الخطأ ← شريحة مخفية **Oops! Try again** بصوت خفيف وزر يعيد للسؤال. في الأعلى اسم اللعبة، وفي الأسفل نقاط التقدم، وفي النهاية **You did it!** وزر **Play again**.
النقر على الخلفية في شرائح الأسئلة لا ينقل للشريحة التالية (الأزرار فقط).

الشكل زجاجي: خلفيات متدرجة ناعمة (`bg/`، يرسمها `backgrounds.js`)، وبطاقات وأزرار شفافة بحواف بيضاء وظل.
إعادة البناء: `node backgrounds.js` ثم `NODE_PATH=<node_modules> node build.js <مجلد>` ثم `python3 game_post.py <مجلد>/02-ba-ta-tha.raw.pptx 02-ba-ta-tha.pptx`.
