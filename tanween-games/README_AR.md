# ألعاب التنوين: ملف لكل تنوين، ثم ملف مراجعة

أربعة عروض PowerPoint، بمجموعة **ألعاب جديدة** غير ألعاب الحركات والمدود والسكون والشدة:
- كل عرض فيه 30 لعبة ولعبتا «برج المكعبات» للفصل.
- كل لعبة 5 جولات.

| الملف | المحتوى |
|---|---|
| `Fathatan-Games.pptx` | تنوين الفتح: بًا، قَلَمًا، والاستثناءات شَجَرَةً وسَمَاءً ومَاءً |
| `Kasratan-Games.pptx` | تنوين الكسر: بٍ، قَلَمٍ، شَجَرَةٍ |
| `Dammatan-Games.pptx` | تنوين الضم: بٌ، قَلَمٌ، شَجَرَةٌ |
| `Tanween-Review-Games.pptx` | الثلاثة معًا: التمييز بينها، و«ما اسمه؟» (فَتۡحَتَانِ، كَسۡرَتَانِ، ضَمَّتَانِ)، والكتابة |

## ماذا يتدرب عليه الطفل
- **Find:** التمييز بين التنوين والحركة والمد: بًا / بَا / بَ، وبٍ / بِي / بِ، وبٌ / بُو / بُ.
- **How do we write it?:** التنوين = الحركة + نون ساكنة، مثل بُ + نۡ ← بٌ.
- **Find (كلمات):** الكلمة بتنوينها الصحيح بين كلمات تشبهها، مثل قَلَمًا / قَلَمَ / قَلَمٌ.
- **Which word has tanween?:** أي كلمة فيها تنوين؟
- **قاعدة الكتابة:** تنوين الفتح يُكتب بعده ألف (بًا) دائمًا، إلا بعد التاء المربوطة (شَجَرَةً) وبعد الهمزة التي قبلها ألف (سَمَاءً). البرنامج يتحقق من ذلك في كل الشرائح.

## الألعاب الجديدة
1. 🐝 **Busy Bee:** النحلة تطير إلى الزهرة الصحيحة، ويمتلئ برطمان العسل.
2. 🐒 **Monkey Climb:** القرد يصعد النخلة خطوة مع كل إجابة صحيحة حتى يصل إلى الموز.
3. 🎯 **Darts:** ارمِ السهم على اللوحة الصحيحة، فتظهر «Bullseye!».
4. 🏀 **Basketball:** صوّب الكرة الصحيحة في السلة، فتظهر «Swish!».
5. 🌱 **Grow a Flower:** البذرة تكبر مع كل إجابة صحيحة حتى تتفتح الزهرة.
6. 🍕 **Pizza Party:** كل إجابة صحيحة تضيف شيئًا إلى البيتزا حتى تكتمل.
7. 🐢 **Turtle Trip:** السلحفاة تمشي على الحجارة حتى تصل إلى بيتها.
8. 🧱 **Block Tower (للفصل):** فريقان. يقرأ الفريق الكلمة ثم يضغط زره فيُضاف مكعب إلى برجه، وأول برج من 5 مكعبات يفوز.

## ملاحظات
- التعليمات بالإنجليزية فقط، وكل ما يُقرأ بالعربي، والسكون برأس الخاء ۡ.
- كل ضغطة **رابط إلى شريحة**، فتعمل على كل الأجهزة.
- شغّل العرض بـ **F5**. السهم الأخضر ينقل إلى اللعبة التالية.
- **لا تحذف الشرائح المخفية:** هي شرائح النتائج.

## إعادة البناء
- `art.js`: الرسوم.
- `audio.py`: الأصوات.
- `build.py`: يبني العروض، ويستخدم محرك `../fun-games` و`../harakat-games`.

```
node art.js && python3 audio.py && python3 build.py .
```
