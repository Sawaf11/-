# المدود الفرعية وعلاماتها وأحكامها (شرح بالإنجليزية، بدون صور)

`Secondary-Madd.pptx`: 38 شريحة، رواية حفص من طريق الشاطبية (مصحف المدينة). العناوين والتوضيحات وملاحظات المعلّم بالإنجليزية، والأمثلة برسم المصحف؛ حرف المد بالأخضر، وسبب المد (الهمز أو السكون) بالأحمر، والنطق بحروف لاتينية.

1. **تذكير بالمد الطبيعي** (حركتان)، و**سببا المد الفرعي**: همز أو سكون، و**علامة المد «~»** (على المتصل والمنفصل واللازم، لا على البدل والعارض واللين).
2. **بسبب الهمز:** المتصل (4–5، و6 عند الوقف على الهمزة): جَآءَ، ٱلسَّمَآءِ، سِيٓءَ، أُو۟لَٰٓئِكَ — المنفصل (4–5): إِنَّآ أَعۡطَيۡنَٰكَ، قُوٓا۟ أَنفُسَكُمۡ، فِيٓ أَنفُسِكُمۡ، والصلة الكبرى مَالَهُۥٓ أَخۡلَدَهُۥ — البدل (2): ءَامَنُوا۟، إِيمَٰنًا، أُوتُوا۟.
3. **بسبب السكون:** اللازم (6): ٱلضَّآلِّينَ، ٱلۡحَآقَّةُ، ءَآلۡـَٰٔنَ، الٓمٓ — العارض للسكون (2/4/6): ٱلرَّحِيمۡ، نَسۡتَعِينۡ، يَعۡلَمُونۡ — اللين (2/4/6 عند الوقف): قُرَيۡشۡ، خَوۡفۡ، ٱلۡبَيۡتۡ — العوض (2): عَلِيمَا.
4. **أقوى المدود:** لازم ← متصل ← عارض ← منفصل ← بدل.
5. **اختبار** (4 شرائح) و**خلاصة**.
