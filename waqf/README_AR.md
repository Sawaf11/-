# الوقف في القرآن: علاماته وكيفيته (شرح بالإنجليزية لغير العرب، بدون صور)

`Stopping-Waqf.pptx`: 37 شريحة، رواية حفص، مصحف المدينة. العناوين والتوضيحات وملاحظات المعلّم بالإنجليزية، والأمثلة برسم المصحف (علامة الوقف بالأحمر، والحرف الذي يتغير عند الوقف بالأخضر، والنطق بحروف لاتينية).

**الجزء الأول: علامات الوقف** — مـ (لازم، يونس 65)، لا (النحل 32)، ج (الكهف 13)، صلى (الأنعام 17)، قلى (الكهف 22)، التعانق ∴ ∴ (البقرة 2)، رأس الآية، السكتة س ومواضعها الأربعة عند حفص.

**الجزء الثاني: كيف نقف على آخر الكلمة**
1. الحركة ← سكون (ٱلنَّاسۡ، خَلَقۡ)
2. تنوين الضم والكسر ← سكون (أَحَدۡ، خَوۡفۡ)
3. تنوين الفتح ← ألف (أَفۡوَاجَا، نِدَآءَا)
4. التاء المربوطة ← هاء ساكنة حتى مع تنوين الفتح (ٱلۡقَارِعَهۡ، رَحۡمَهۡ)
5. الألف المقصورة المنونة ← ألف (هُدَى)
6. هاء الضمير ← هاء ساكنة بلا صلة (يَرَهۡ، رَبَّهۡ، وَٱسۡتَغۡفِرۡهۡ)
7. مد أو لين قبل الحرف الأخير ← عارض للسكون 2/4/6 (ٱلرَّحِيمۡ، قُرَيۡشۡ)
8. القلقلة أقوى عند الوقف (خَلَقۡ)
9. الحرف المشدد يبقى مشدداً (وَتَبّۡ، مُسۡتَقَرّۡ)
10. حرف المد في الآخر يبقى (وَٱلضُّحَىٰ)
11. الصفر المستطيل ← تُقرأ الألف (أَنَا)
ثم الروم والإشمام (للمعلّمين)، والابتداء بعد الوقف، واختبار (4 شرائح)، وخلاصة.
