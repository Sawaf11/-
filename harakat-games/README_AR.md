# ألعاب الحركات التفاعلية (فتحة – كسرة – ضمة – مجمعة)

أربعة عروض PowerPoint تفاعلية، كل عرض 83 شريحة، وفيها ألعاب مختلفة مخلوطة داخل العرض نفسه:

| الملف | المحتوى |
|---|---|
| `Fathah-Games.pptx` | ألعاب الفتحة |
| `Kasrah-Games.pptx` | ألعاب الكسرة |
| `Dammah-Games.pptx` | ألعاب الضمة |
| `Harakat-Mix-Games.pptx` | الحركات الثلاث مجمعة (يميّز الطفل بينها) |
| `Harakat-Games-All.zip` | الأربعة في ملف واحد |

## الألعاب داخل كل عرض
قبل أول ظهور لكل لعبة توجد شريحة «How to play» بالإنجليزية.

1. **فرقعة البالونات (14 شريحة):** البالونات تتحرك. اضغط على البالون الصحيح فينفجر مع صوت ونجمة، أما الخطأ فيهتز.
2. **إطعام الوحش (14 شريحة):** الطعام الصحيح يطير إلى فم الوحش فيمضغه ويقول «Yummy!»، أما الخطأ فيحزن الوحش.
3. **اصطد السمكة (14 شريحة):** الأسماك تسبح. اضغط على السمكة الصحيحة فتختفي مع صوت ونجمة.
4. **الحروف القافزة (14 شريحة):** اختر 3 حروف صحيحة من 6.
5. **قطار الكلمات (9 شرائح):** اضغط الحروف بالترتيب فتركب العربات، ثم اضغط GO فيتحرك القطار وتظهر الكلمة.
6. **الهدايا المفاجئة (7 شرائح):** 8 صناديق، تحت كل صندوق حرف أو كلمة يقرؤها الطفل.
7. **سباق الفريقين (شريحتان):** لعبة للفصل كله. يقرأ الفريق الكلمة ثم يضغط زر فريقه فتتقدم سيارته، وأول سيارة تصل تفوز.

## طريقة التشغيل
- شغّل العرض بوضع **Slide Show** (F5)؛ الألعاب لا تعمل في وضع التحرير.
- في شرائح الألعاب لا ينتقل الضغط على الخلفية إلى الشريحة التالية، لكي لا ينتقل الطفل بالخطأ. للانتقال اضغط **السهم الأخضر** أسفل اليمين.
- في الشريحة الأخيرة زر **Play again** للعودة إلى البداية.
- الخلفيات بألوان باستيل هادئة ومختلفة حسب اللعبة.
- الأصوات قصيرة ومصاحبة للعب، وهي مدمجة في الملف.

## للتعديل وإعادة البناء
- `art.js`: يرسم الصور والخلفيات.
- `audio.py`: يولّد الأصوات.
- `build.py`: يبني العروض (قوائم الكلمات في `WORDS`).

```
node art.js && python3 audio.py && python3 build.py .
```
