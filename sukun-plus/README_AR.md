# السكون في القرآن الكريم

## `Sukun-Explained.pptx` — شرح السكون لغير العرب (21 شريحة، بدون صور)
بالأشكال والحروف، وكل شريحة فيها ملاحظات للمعلّم بالعربية:
1. **الشكل:** في المصحف رأس خاء صغيرة بلا نقطة «ۡ»، وفي الكتب دائرة «ْ». مأخوذ من رأس الخاء.
2. **المعنى:** الحركة صوت يجري (سهم أخضر)، والسكون وقوف الصوت على الحرف (إشارة قف حمراء).
3. **لا نبدأ بساكن:** «بۡ» وحدها خطأ، و«أَبۡ» صحيح.
4. **الجمع:** متحرك + ساكن = مقطع واحد: أَبۡ، إِبۡ، أُبۡ، ثم في وسط الكلمة: بَحۡرٌ، شَمۡسٌ، قَلۡبٌ.
5. **في المصحف:**
   - العلامة تعني النطق الواضح: أَنۡعَمۡتَ، ٱلۡحَمۡدُ.
   - حرف بلا علامة وبعده مشدد = إدغام: مِن رَّبِّهِمۡ.
   - حرف بلا علامة وبعده غير مشدد = إخفاء: مِن تَحۡتِهَا.
   - حروف المد بلا سكون: قَالَ.
   - الدائرة الصغيرة «۟» = لا يُقرأ أبداً: قَالُوا۟، أُو۟لَٰٓئِكَ.
   - الصفر المستطيل «۠» = يُقرأ في الوقف فقط: أَنَا۠.
   - السكون عند الوقف: ٱلرَّحِيمِ ← ٱلرَّحِيمۡ.
   - القلقلة (قطب جد): قَدۡ أَفۡلَحَ، يَجۡعَلُونَ.

الخط Traditional Arabic (موجود في Windows) لأنه يرسم العلامات القرآنية.

إعادة البناء: `NODE_PATH=<node_modules> node explain.js <مجلد>` ثم `python3 ../fathah-plus/post.py <مجلد>/Sukun-Explained.raw.pptx Sukun-Explained.pptx`

## `drills/` — ملفات تدريب السكون (16 ملفاً، 1,330 شريحة، بدون صور)
نفس نظام الفتحة والكسرة والضمة: الحروف حسب الشكل، وكل حرف ساكن (دائرة حمراء، بسكون المصحف «ۡ») مع الحروف التي قبله:
- **أول الكلمة:** الحرف بحركة ثم حرف ساكن (جِ + بۡ = جِبۡ).
- **وسط الكلمة:** حرف متحرك + الحرف الساكن + حرف متحرك (تُ + جۡ + ثَ = تُجۡثَ).
- **آخر الكلمة:** حرف متحرك + الحرف الساكن (ثِ + جۡ = ثِجۡ).

الحركة قبل الساكن تتناوب بين الفتحة والكسرة والضمة. يبدأ كل ملف بشريحة «لا نبدأ بساكن» (جۡ ✗ / أَجۡ ✓) ثم أَجۡ، إِجۡ، أُجۡ. وفي ملاحظات حروف القلقلة (ق ط ب ج د) تنبيه على القلقلة. وفي آخر كل ملف آيات فيها حرف الملف ساكناً، مثل «وَٱلشَّمۡسُ تَجۡرِي»، «قَدۡ أَفۡلَحَ ٱلۡمُؤۡمِنُونَ»، «إِيَّاكَ نَعۡبُدُ»؛ والبرنامج يتأكد أن كل آية فيها حرف الملف بسكون.
إعادة البناء: `cd drills && NODE_PATH=<node_modules> node build.js <مجلد>` ثم `python3 ../../fathah-plus/post.py`.
